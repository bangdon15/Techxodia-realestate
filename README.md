# VALENCE // DOMAIN
### Bespoke Architectural Holdings & Curated Monoliths

An ultra-modern, editorial real estate portfolio web application that breaks away from generic template layouts. Built with bespoke vanilla technologies, high-density typography, asymmetrical masonry grid dynamics, and a dynamic data mapping architecture.

---

## 🏛️ Features

- **Editorial Aesthetic ("Anti-Template")**: Deep charcoal palette (`#090a0d`, `#0f1116`), alabaster typography (`#f6f5f1`), and muted earth-tone accents (Travertine `#cfb89d`, Champagne Gold `#e5cfad`, Terracotta `#bd6a4c`, Nordic Sage `#5e6b5d`).
- **Dynamic Top-Value Hero Carousel**: Auto-rotates across high-resolution full-bleed backgrounds dynamically pulling from the top 3 highest-valued acquisitions.
- **Asymmetrical Staggered Masonry Grid**: Non-uniform layout with varied card spans, panoramic lead anchors, and an editorial typographic breather card.
- **Interactive Database Query Engine**: Real-time pill toggles to filter by architectural style and transactional status without page reload.
- **Native `<dialog>` Quick-View Modal**: Hardware-accelerated slide-out drawer featuring an interactive multi-image thumbnail gallery, extended technical specifications (sqft, year built, architect, GPS coordinates), curatorial statements, confidential agent notes, and direct dossier request simulation with toasts.
